필요해지면 그때 추가한다.

**수용 기준:** `npm test`가 통과하고, 일부러 마커를 지우면 실패한다.

## T0.5 — 라우팅 정리

현재 `App.tsx`의 해시 라우팅은 `/`와 `/notice` 두 갈래를 if로 처리한다. 갈래가
셋이 되므로 정리한다.

- [ ] 라우트 테이블을 자료구조로 뽑는다 (경로 → 지연 로드 컴포넌트)
- [ ] 알 수 없는 경로는 웰컴으로 되돌린다
- [ ] 페이지 내 앵커 구분 로직은 그대로 유지 — 이미 한 번 버그가 났던 지점이다

**정식 라우터(react-router)는 아직 도입하지 않는다.** 갈래가 셋이고 중첩 경로가
없다. 캠페인 기록지(축 ①)에 들어가면서 중첩·파라미터가 필요해질 때 교체하고,
그때도 GitHub Pages 때문에 HashRouter를 쓴다.

**수용 기준:** `#/`, `#/notice`, `#/satchel`(빈 화면이라도) 세 경로가 동작하고,
`#/없는경로`는 웰컴으로 간다.
