# N4 — 전투 세션

방을 만들고, 알리고, 참여시킨다. **아직 공유하는 값은 없다** — 참여자 목록이
실시간으로 늘고 주는 것까지가 이 마일스톤이다.

선행: N3 · 정본: [`../SPEC.md`](../SPEC.md) 5.4 / 6.2 · 전체 그림: [N0](./N0-네트워킹-설계.md)

---

## 왜 값 없이 방부터 만드는가

방과 값을 같이 만들면 **안 맞는 것이 방 문제인지 값 문제인지 가릴 수 없다.**
참여자 목록만으로도 배관은 전부 검증된다 — 구독이 붙는가, 남이 들어온 것이
보이는가, 끊기면 어떻게 되는가, 돌아오면 맞춰지는가.

여기가 튼튼하면 N5는 값 하나를 얹는 일이 된다.

---

## 목표

1. 파티원이면 **누구나** 전투를 연다.
2. 접속 중인 파티원이 **새 전투가 열렸음을 안다.**
3. 알림을 받은 사람이 **참여를 고른다.** 자동으로 끌려들어가지 않는다.
4. 참여자 목록이 실시간으로 갱신된다.
5. 끊기면 **혼자 모드로 강등**하고, 돌아오면 다시 붙는다.

---

## 참여는 고르는 것이다

파티원이 여섯인데 오늘 넷만 모였을 수 있다. 접속해 있다고 자동으로 전투에
들어가면 **집에 있는 사람의 화면이 남의 판을 따라 움직인다.**

알림은 "열렸다"까지고, 참여는 누르는 것이다.

---

## 끊기면 판을 멈추지 않는다

집이 아닌 곳에서 하면 가정용 회선을 거친다. 끊김은 예외가 아니라 일상이다.

- 끊기면 **혼자 모드로 강등한다.** 로컬로 계속 쓴다. 화면을 얼리지 않는다.
- 끊겼다는 것은 **눈에 띄되 방해하지 않게** 알린다. 원소를 미는 손을 막지 않는다.
- 돌아오면 다시 붙는다. 값이 다르면 N5에서 한 번 묻는다.

---

## 할 일

### 전투 열기

- [ ] 파티 화면에서 "전투 시작". 파티원이면 누구나.
- [ ] 이미 그 파티에 진행 중인 전투가 있으면 새로 만들기 전에 알린다.
- [ ] 연 사람은 자동으로 참여자가 된다.

### 알림

- [ ] 접속 중인 파티원에게 배너. Supabase Realtime 구독으로 받는다.
- [ ] **어느 파티의 전투인지 보여준다.** 여러 파티에 속할 수 있으므로 파티 이름이
      없으면 어디서 온 알림인지 알 수 없다.
- [ ] 배너에서 바로 참여하거나 무시한다. 무시한 것은 다시 볼 수 있어야 한다 —
      나중에 합류하는 일이 흔하다.

### 참여와 이탈

- [ ] 참여 / 나가기.
- [ ] 참여자 목록이 실시간으로 갱신된다.
- [ ] 지금 어느 전투에 있는지 행낭 화면에서 **항상 보인다.** 공유되는 중인지
      아닌지 모르면 값을 믿을 수 없다.
- [ ] 전투 종료. 누가 끝낼 수 있는지 정한다(연 사람만? 누구나?).

### 연결 상태

- [ ] 붙음 / 끊김 / 다시 붙는 중을 구분해 들고 있는다.
- [ ] 끊기면 강등하고 표시한다. 로컬 조작은 계속 받는다.
- [ ] 다시 붙으면 참여자 목록부터 맞춘다.
- [ ] 재연결은 물러나며 다시 시도한다(backoff). 촘촘히 두드리면 무료 등급의
      연결 한도를 먼저 태운다.

### 수명 관리

- [ ] 명시적 종료.
- [ ] 무활동 자동 정리. 안 그러면 서버에 빈 방이 쌓인다.
- [ ] 정리된 방에 남아 있던 사람에게 그 사실을 알린다.

---

## 검증

- [ ] 두 창을 띄워 한쪽에서 전투를 열면 다른 쪽에 배너가 뜬다.
- [ ] 참여하면 양쪽 참여자 목록에 나타난다.
- [ ] 나가면 사라진다.
- [ ] 서버를 끄면 강등 표시가 뜨고 **행낭은 계속 쓸 수 있다.**
- [ ] 서버를 다시 켜면 스스로 붙는다.
- [ ] 파티에 속하지 않은 사람이 전투에 참여를 시도하면 서버가 막는다(`curl`).
- [ ] 한 사람이 파티 둘에 속할 때 두 파티의 전투 알림이 구별된다.

---

## 열린 질문

- **전투 알림을 앱 밖까지 보낼 것인가.** 앱이 열려 있을 때의 배너는 구독으로 된다.
  닫힌 상태까지 알리려면 Web Push가 필요하고, iOS는 홈 화면 추가와 권한 요청이
  따라붙는다. **1단계는 배너만.** 실제로 "다들 앱을 열어놓고 시작하는지"를 보고
  판단한다.
- **한 사람이 두 전투에 동시에 참여할 수 있는가.** 행낭의 내부 상태가 하나뿐이라
  막는 쪽이 자연스럽다.
- **무활동 기준 시간.** 한 판이 실제로 얼마나 걸리는지 보고 정한다. 짧게 잡으면
  화장실 다녀온 사이에 방이 사라진다.
- **누가 전투를 끝낼 수 있는가.** 연 사람만으로 두면 그 사람이 먼저 자리를 뜰 때
  곤란해진다.
